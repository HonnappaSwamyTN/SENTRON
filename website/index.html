Subsystem 01

AgentGuard: Deterministic AI-Agent Governance

Autonomous AI agents operating on desktop environments can execute destructive commands, leak credentials, or fall victim to indirect prompt injection. AgentGuard intercepts, inspects, and enforces permissions before execution.

Prompt-Injection Detection

Deterministic rule-based pattern analyzer that detects prompt injections, instruction overrides, jailbreak heuristics, and context delimiter breakouts in untrusted payloads. Emits structured RiskSignal records before any tool runs.

AC-01 Verified Zero Cloud Inference Heuristic Scanner

Secret Detection & Redaction

Automated regex and high-entropy detection for OpenAI, GitHub, AWS, and Google API keys, Bearer headers, and database passwords. All recognized secrets are sanitized into [REDACTED_*] tokens before saving to local SQLite audit tables.

AC-02 Verified Idempotent Redaction Privacy by Design

Scoped ALLOW / ASK / BLOCK

Deterministic policy engine maps actions to authoritative decisions. Enforces strict default-deny. High-impact operations trigger human approval scopes bound by agent ID, tool, and target. Destructive operations (e.g. format_disk) are permanently blocked.

Subsystem 02

CrashGuard: Real-Time Windows Stability & Diagnostics

Autonomous workloads can lead to severe system degradation, memory exhaustion, and deadlocks. CrashGuard delivers honest hardware telemetry, filters transient spikes, and captures genuine Windows crash evidence.

psutil Hardware Telemetry

Dedicated background monitoring thread samples authentic CPU (total & per-core), physical RAM, free disk space, and top memory-consuming processes. Strict guarantee: simulated data is never presented as real hardware telemetry.

AC-09 Verified Dedicated Thread Circular Buffer

Sustained-Risk Detection

Transient load spikes do not indicate a crash. CrashGuard evaluates metrics against configurable duration windows (e.g. >85% load sustained for 15s) with anti-flapping alert cooldowns, preventing alert fatigue while catching real saturation.

AC-10 Verified Window Evaluation Anti-Flapping

Windows Event Evidence

Queries native Windows Event Logs across Application and System channels. Distinguishes confirmed observations from inferred hypotheses for crashes, UI hangs, and unclean shutdowns with persistent JSON deduplication.

AC-11 & AC-12 7 Event Channels Native Adapter

System Architecture

How SENTRON Works Under the Hood

A modular monolith designed for sub-millisecond local policy execution and low-overhead system monitoring.

01

Action Interception

AI-agent action requests pass into AgentGuard. Prompts and payload arguments are inspected deterministically for injection signatures and confidential API keys.

02

Policy Enforcement

The policy engine matches explicit agent rules. Blocked actions fail closed immediately. Sensitive or high-impact actions require scoped human approval.

03

Telemetry Sampling

CrashGuard worker thread samples OS hardware metrics every 5–10 seconds. Sliding windows identify sustained saturation while ignoring harmless transient spikes.

04

Correlated Audit Trail

Redacted security logs and system diagnostic events persist to private local SQLite storage, enabling temporal correlation between agent activities and OS health.

Trust & Boundaries

Privacy Guarantees & Explicit V1 Limitations

We believe security software must be radically honest about what it does and what it explicitly does not do.

100% Offline & Local-First

Zero mandatory cloud infrastructure, zero telemetry collection, zero remote analytics, and zero phone-home pings. All decisions execute locally on your machine.

Local SQLite Audit Store

Security audit logs and telemetry records are stored in %LOCALAPPDATA%\SENTRON\sentron_local.db. Secrets are redacted prior to storage.

No External AI API

The decision engine uses deterministic heuristics and regexes. There are no external LLM API calls in the security gate, eliminating hallucinations and latency.

Controlled Execution Boundary & Safe Mock Executor

SENTRON protects actions that pass through its supported controlled execution boundary. It makes no claim of universal interception for arbitrary third-party software that bypasses the SENTRON gatekeeper. Furthermore, the V1 demo dispatches approved actions to a safe mock executor to simulate approved tasks safely without executing destructive host shell commands.

Windows SmartScreen / "Unknown Publisher" Notice

Because SENTRON is an open-source community project and the binary is not signed with an expensive commercial Extended Validation (EV) code-signing certificate, Windows SmartScreen will display an "Unknown Publisher / Windows protected your PC" warning on first run:

  1. Click "More info" on the Windows SmartScreen dialog.
  2. Verify the publisher indicates SENTRON Security and matches the SHA-256 checksum published above.
  3. Click "Run anyway" to proceed with the per-user installation.
  4. Note: Never ignore genuine antivirus warnings. If you prefer, clone the repository and run directly from verified source code.
Step 01

Run Setup Executable

Launch SENTRON_Setup.exe. The Inno Setup wizard installs the application into your local user directory (%LOCALAPPDATA%\Programs\SENTRON) without requiring admin elevation.

Step 02

Desktop Hub Appears

SENTRON creates a Start Menu entry and launches the movable floating golden shield widget on your desktop. Click the shield at any time to open the diagnostic panel.

Step 03

Automatic Local Protection

CrashGuard starts its background telemetry loop and Event Log monitoring immediately. All private events and policies are recorded in your local SQLite database.
